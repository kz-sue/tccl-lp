TaskChute Cloud Lite

利用規約

この利用規約（以下「本規約」といいます）は、ZOELAB（以下「当方」といいます）が提供するスマートフォン向けアプリケーション「TaskChute Cloud Lite」（以下「本アプリ」といいます）を利用するすべての方に適用されます。 本アプリをインストールまたは利用した時点で、本規約に同意したものとみなされます。本規約に同意いただけない場合は、本アプリを利用しないでください。

第1条（定義）

本規約では、次の用語を以下の意味で使います。

  1. 「本アプリ」とは、当方が App Store および Google Play を通じて配信するアプリケーション「TaskChute Cloud Lite」（ストア上の表示名「TCC Lite」を含みます）をいいます。
  2. 「ユーザー」とは、本アプリをインストールし、利用するすべての方をいいます。
  3. 「無料プラン」とは、料金を支払わずに利用できる本アプリの基本機能をいいます。
  4. 「Plusプラン」とは、第5条に定める有料のサブスクリプション（定期購入）をいいます。
  5. 「ストア」とは、Apple Inc. が運営する App Store、および Google LLC が運営する Google Play をいいます。
  6. 「TaskChute Cloud 2」とは、jMatsuzaki株式会社が運営するWebサービス「TaskChute Cloud 2」をいいます。
  7. 「ユーザーデータ」とは、ユーザーが本アプリに入力または添付したタスク、ルーチン、セクション、コメント（メモ）、画像などの情報をいいます。
  8. 「プライバシーポリシー」とは、当方が https://tccl.zoelab.jp/privacy/ に掲載する本アプリのプライバシーポリシーをいいます。

第5条（無料プランと Plus プラン）

  1. 本アプリは、TaskChute Cloud 2 のアカウントがなくても、無料で利用を開始できます。
  2. 無料プランには、次の制限があります。制限の具体的な数値は、当方のWebサイトまたは本アプリ内の表示をご確認ください。
    • 1日に登録できるタスクの件数
    • 登録できるルーチンの件数
    • 閲覧・操作できる日付の範囲（今日を含む前後一定期間）
  3. Plus プランに加入すると、前項の制限がなくなり、あわせて TaskChute Cloud 2 とのアカウント連携および同期機能を利用できます。
  4. TaskChute Cloud 2 との同期を利用するには、Plus プランへの加入に加えて、TaskChute Cloud 2 のアカウントが必要です。TaskChute Cloud 2 の利用には、jMatsuzaki株式会社が定める利用規約（https://www.taskchute.cloud/terms.html）が別途適用されます。TaskChute Cloud 2 側のプランに制限がある場合、その制限を超えて同期することはできません。
  5. Plus プランの料金に、TaskChute Cloud 2 の有料プランの料金は含まれません。TaskChute Cloud 2 の有料プランの契約、料金の支払い、解約および返金は、jMatsuzaki株式会社との間で、同社の利用規約に従って行われるものとし、当方は関与しません。
  6. 当方は、各プランの内容および無料プランの制限を、第11条の定めに従って変更することがあります。

第6条（サブスクリプションの条件）

  1. Plus プランは、月額プランおよび年額プランのサブスクリプション（自動更新型の定期購入）として、ストアを通じて販売します。価格は、ストアおよび本アプリ内の購入画面に表示される金額（消費税込み）とします。
  2. 購入時の決済は、ストアが提供する決済手段により行われます。当方がユーザーの決済情報（クレジットカード番号など）を取得することはありません。
  3. Plus プランは、ユーザーが解約しない限り、各契約期間の終了時に同じ期間で自動的に更新され、更新時にストアのアカウントに対して料金が請求されます。初回の料金は購入確定時に請求されます。
  4. Plus プランには、7日間の無料トライアル期間があります。トライアル期間中は料金が発生せず、Plus プランの機能を利用できます。トライアル期間中に解約しない場合、トライアル期間の終了時に自動的に有料の契約に移行し、選択したプランの料金が請求されます。無料トライアルは、ストアのアカウントごとに1回に限り利用できます。トライアルの提供条件はストアの購入画面にも表示されます。
  5. 解約は、ユーザーご自身が、ご利用のストアのサブスクリプション管理画面（iOS: 「設定」→ Apple アカウント → 「サブスクリプション」、Android: Google Play の「定期購入」）から行います。本アプリ内から解約することはできません。また、本アプリをアンインストールしただけでは解約になりません。
  6. 解約した場合でも、支払い済みの契約期間の終了日までは Plus プランを利用できます。契約期間の終了後は自動的に無料プランに戻り、無料プランの制限が再び適用されますが、それまでに作成したユーザーデータが削除されることはありません。
  7. 返金は、各ストアが定める規約および手続きに従います。デジタルコンテンツという性質上、当方が直接返金に応じることは原則としてできません。返金をご希望の場合は、ご利用のストアにお申し出ください。
  8. 当方は、Plus プランの価格を変更することがあります。価格を変更する場合、当方は、変更の効力発生日より前に、ストアの仕組みまたは本アプリ内での表示によりユーザーに通知します。ストアの規約により、ユーザーの同意が必要とされる値上げについては、ユーザーが同意しない限り変更後の価格は適用されず、サブスクリプションが終了する場合があります。
  9. Plus プランは、購入時に使用したストアのアカウントに紐づきます。機種変更や再インストールをした場合は、本アプリ内の「購入を復元」から、同じストアのアカウントで購入状態を復元できます。TaskChute Cloud 2 のアカウントと連携している場合は、他の端末で同じアカウントにログインすることで Plus プランを引き継ぐことができます。
  10. 通信料など、本アプリの利用に必要なインターネット接続にかかる費用は、ユーザーの負担とします。

プライバシーポリシー

ZOELAB（以下「当方」といいます）は、当方が提供するアプリケーション「TaskChute Cloud Lite」（以下「本アプリ」といいます）における、 ユーザーの情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

1. 収集する情報

(1) アカウント情報（TaskChute Cloud 2 と連携する場合のみ）

本アプリは、TaskChute Cloud 2 のアカウントと連携（ログイン）する場合に限り、以下の情報を取得します。 連携しない場合、アカウント情報を取得することはありません。

  • メールアドレス
  • 表示名・プロフィール画像のURL（Google アカウントまたは Apple ID でログインした場合に、各サービスから提供されるもの）
  • 認証用の識別子（ユーザーID）
  • 端末のタイムゾーンおよび言語設定（アカウント新規登録時）

(2) ユーザーが作成する情報

ユーザーが本アプリに入力したタスク名、見積時間、開始・終了時刻、ルーチン設定、セクション設定、コメント（メモ）、 コメントに添付した画像などの情報は、端末内に保存されます。 TaskChute Cloud 2 のアカウントと連携している場合、これらの情報（コメントおよび添付画像を含みます）は、 サービス提供のために TaskChute Cloud 2 のサーバーにも保存され、Web版および他の端末と同期されます。 連携していない場合、これらの情報が端末の外部に送信されることはありません。

(3) 利用状況に関する情報

本アプリは、品質改善のため、Google Analytics for Firebase を利用して以下の情報を収集します。

  • アプリの操作イベント（タスクの作成・開始・完了、チュートリアルの進行状況など、操作の種別を示す情報）
  • 利用傾向を示す統計的な情報（登録タスク数の規模、クラウド連携の有無など、範囲・区分に丸めた情報）
  • 端末に関する情報（OSの種類・バージョン、機種名、アプリのバージョンなど、Google Analytics for Firebase が標準的に収集する情報）

これらの収集にあたり、タスク名・コメント本文・メールアドレスなどの入力内容そのものを送信することはありません。 また、広告識別子（AAID / IDFA）は収集せず、広告目的のトラッキングも行いません。 利用状況の収集は、本アプリの設定画面からいつでも無効にできます。

(4) 位置情報について

本アプリは位置情報の取得・収集を行いません。 iOS版において位置情報に関する許可の説明文が表示される場合がありますが、 これはタイムゾーンの判定に使用しているライブラリの技術的な要件によるものであり、位置情報を取得するものではありません。

2. 利用目的

収集した情報は、以下の目的で利用します。

  • 本アプリおよび TaskChute Cloud 2 との同期機能の提供・維持のため
  • ユーザーの認証および本人確認のため（ログイン用ワンタイムコードの送付を含みます）
  • 本アプリの品質改善・機能改善のため
  • 不具合の調査・対応のため
  • お問い合わせへの対応のため

3. 第三者サービスの利用

本アプリでは、クラウド同期、認証および利用状況の分析のために以下の第三者サービスを利用しています。 これらのサービスによる情報の取り扱いについては、各サービスのプライバシーポリシー等をご確認ください。

  • TaskChute Cloud 2（運営: jMatsuzaki株式会社） — アカウント連携時、アカウント情報およびユーザーが作成した情報の同期・保存に利用します。
    TaskChute Cloud 2 利用規約
  • Firebase（Firebase Authentication / Google Analytics for Firebase）・Google ログイン（提供: Google LLC）
    Google プライバシーポリシー / Firebase のプライバシーとセキュリティ
  • Sign in with Apple（提供: Apple Inc.、iOS版のみ）
    Apple プライバシーポリシー

本アプリは広告配信サービスを利用していません。

4. 第三者への提供

当方は、法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供することはありません。

5. 端末の機能・権限の利用

本アプリは、以下の端末機能を利用します。いずれもユーザーの許可なく利用することはありません。

  • 通知 — タスクの開始予定時刻、見積時間の超過、セクションの切り替わりをお知らせするために使用します。通知はすべて端末内で生成され（ローカル通知）、プッシュ通知の配信は行いません。
  • カメラ — 写真を撮影してコメントに添付するために使用します。
  • 写真ライブラリ・ファイル — 画像を選択してコメントに添付するために使用します。

6. 情報の保存期間と削除

  • 端末内に保存された情報は、本アプリをアンインストールすることで削除されます。
  • TaskChute Cloud 2 と連携して同期された情報は、本アプリからログアウトまたはアンインストールした後もサーバー上に保持されます。 サーバー上の情報の削除を希望する場合は、TaskChute Cloud 2（Web版）の退会手続きを行ってください。
  • 退会手続きを行うことが難しい場合は、下記のお問い合わせ先までご連絡ください。

7. 本ポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。 変更後のプライバシーポリシーは、本ページに掲載した時点から効力を生じるものとします。

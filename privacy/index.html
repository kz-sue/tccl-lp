プライバシーポリシー

English

ZOELAB（以下「当方」といいます）は、当方が提供するアプリケーション「TaskChute Cloud Lite」（以下「本アプリ」といいます）における、 ユーザーの情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

1. 収集する情報

(1) アカウント情報（TaskChute Cloud 2 と連携する場合のみ）

本アプリは、TaskChute Cloud 2 のアカウントと連携（ログイン）する場合に限り、以下の情報を取得します。 連携しない場合、アカウント情報を取得することはありません。

  • メールアドレス
  • 表示名・プロフィール画像のURL（Google アカウントまたは Apple ID でログインした場合に、各サービスから提供されるもの）
  • 認証用の識別子（ユーザーID）
  • 端末のタイムゾーンおよび言語設定（アカウント新規登録時）

(2) ユーザーが作成する情報

ユーザーが本アプリに入力したタスク名、見積時間、開始・終了時刻、ルーチン設定、セクション設定、コメント（メモ）、 コメントに添付した画像などの情報は、端末内に保存されます。 TaskChute Cloud 2 のアカウントと連携している場合、これらの情報（コメントおよび添付画像を含みます）は、 サービス提供のために TaskChute Cloud 2 のサーバーにも保存され、Web版および他の端末と同期されます。 連携していない場合、これらの情報が端末の外部に送信されることはありません。

(3) 利用状況に関する情報

本アプリは、品質改善のため、Google Analytics for Firebase を利用して以下の情報を収集します。

  • アプリの操作イベント（タスクの作成・開始・完了、チュートリアルの進行状況など、操作の種別を示す情報）
  • 利用傾向を示す統計的な情報（登録タスク数の規模、クラウド連携の有無など、範囲・区分に丸めた情報）
  • 端末に関する情報（OSの種類・バージョン、機種名、アプリのバージョンなど、Google Analytics for Firebase が標準的に収集する情報）
  • 個人を特定しない識別子（アプリインスタンスID。端末ごとにランダムに付与される、利用状況の集計のための識別子）

これらの情報は Google LLC のサーバーに送信され、同社のプライバシーポリシーに基づき処理されます。 収集にあたり、タスク名・コメント本文・メールアドレスなどの入力内容そのものを送信することはありません。 また、広告識別子（AAID / IDFA）は収集せず、広告目的のトラッキングその他の広告目的の処理も行いません。 Google の同意モード（Consent Mode）において、ユーザーの同意設定に連動するのは分析用データの保存（analytics_storage）のみであり、 広告に関する項目（ad_storage、ad_user_data、ad_personalization_signals）は常に「拒否」に設定しています。

利用状況の収集の取り扱いは、ユーザーの所在地域によって次のとおり異なります。

  • 欧州経済領域（EEA）、英国またはスイスのユーザー — 端末のロケール（国・地域の設定）またはタイムゾーンからこれらの地域に所在すると判定された端末では、 初回起動時に、利用状況の収集について同意を求める画面を表示します。 同意が得られるまで、利用状況の収集は一切開始されません（初回起動を示すイベントなど、自動的に収集される情報も含みます）。 同意しない場合でも、本アプリのすべての機能を利用できます。 同意はいつでも「設定 → アプリ情報 → 利用状況の送信」から撤回でき、同意しなかった場合または撤回した場合には、 収集を停止するとともに、端末上に保存されている利用状況の分析に関するデータ（アプリインスタンスIDなど）を消去します。 同じ設定から、あとで再び同意することもできます。
  • その他の地域のユーザー — 利用状況の収集は既定で有効です。「設定 → アプリ情報 → 利用状況の送信」からいつでも無効にできます。

(4) 購入に関する情報（Plus プランを購入する場合のみ）

本アプリは、アプリ内課金（Plus プラン）の購入状態を管理するために RevenueCat（提供: RevenueCat, Inc.）を利用しており、 以下の情報が RevenueCat のサーバーに送信・保存されます。

  • 匿名の App User ID（RevenueCat が端末ごとに発行する識別子。TaskChute Cloud 2 と連携している場合は、そのユーザーIDと紐付けられます）
  • 購入およびサブスクリプションの状態（加入中のプラン、有効期間、トライアルの利用状況など）
  • ストア（App Store / Google Play）が発行する取引識別子およびレシート情報

クレジットカード番号などの決済情報は Apple または Google が処理し、当方および RevenueCat に渡ることはありません。 本アプリの設定画面に表示される「サポートID」は、この App User ID です。

(5) 位置情報について

本アプリは位置情報の取得・収集を行いません。 iOS版において位置情報に関する許可の説明文が表示される場合がありますが、 これはタイムゾーンの判定に使用しているライブラリの技術的な要件によるものであり、位置情報を取得するものではありません。 なお、Google Analytics for Firebase が IP アドレスから国・地域レベルの大まかな位置を推定する場合がありますが、 端末の位置情報機能を利用するものではありません。

2. 利用目的

収集した情報は、以下の目的で利用します。

  • 本アプリおよび TaskChute Cloud 2 との同期機能の提供・維持のため
  • ユーザーの認証および本人確認のため（ログイン用ワンタイムコードの送付を含みます）
  • Plus プランの購入状態の確認および復元のため
  • 本アプリの品質改善・機能改善のため
  • 不具合の調査・対応のため
  • お問い合わせへの対応のため（サポートIDによる購入状態の確認を含みます）

3. 第三者サービスの利用

本アプリでは、クラウド同期、認証、アプリ内課金の管理および利用状況の分析のために以下の第三者サービスを利用しています。 これらのサービスによる情報の取り扱いについては、各サービスのプライバシーポリシー等をご確認ください。

  • TaskChute Cloud 2（運営: jMatsuzaki株式会社） — アカウント連携時、アカウント情報およびユーザーが作成した情報の同期・保存に利用します。
    TaskChute Cloud 2 利用規約
  • Firebase（Firebase Authentication / Google Analytics for Firebase）・Google ログイン（提供: Google LLC）
    Google プライバシーポリシー / Firebase のプライバシーとセキュリティ
  • Sign in with Apple（提供: Apple Inc.、iOS版のみ）
    Apple プライバシーポリシー
  • RevenueCat（提供: RevenueCat, Inc.） — Plus プランの購入状態の管理・確認・復元に利用します。
    RevenueCat プライバシーポリシー

本アプリは広告配信サービスを利用していません。

4. 第三者への提供

当方は、法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供することはありません。

5. 安全管理措置

本アプリとサーバー（TaskChute Cloud 2 および第三者サービス）との間のデータの送受信は、TLSにより暗号化されます。 当方は、取り扱う情報の漏えい、滅失または毀損の防止その他の安全管理のために、必要かつ適切な措置を講じます。

6. 端末の機能・権限の利用

本アプリは、以下の端末機能を利用します。いずれもユーザーの許可なく利用することはありません。

  • 通知 — タスクの開始予定時刻、見積時間の超過、セクションの切り替わりをお知らせするために使用します。通知はすべて端末内で生成され（ローカル通知）、プッシュ通知の配信は行いません。
  • カメラ — 写真を撮影してコメントに添付するために使用します。
  • 写真ライブラリ・ファイル — 画像を選択してコメントに添付するために使用します。

7. 情報の保存期間と削除

  • 端末内に保存された情報は、本アプリをアンインストールすることで削除されます。
  • TaskChute Cloud 2 と連携して同期された情報は、本アプリからログアウトまたはアンインストールした後もサーバー上に保持されます。 サーバー上の情報の削除を希望する場合は、TaskChute Cloud 2（Web版）の退会手続きを行ってください。 手順はアカウントの削除のページをご覧ください。
  • 退会手続きを行うことが難しい場合は、下記のお問い合わせ先までご連絡ください。

8. EU/EEA・英国・スイスのユーザーについて

欧州経済領域（EEA）、英国またはスイスに所在するユーザーには、前各条に加えて、 EU 一般データ保護規則（GDPR）、英国 GDPR およびスイス連邦データ保護法に基づき、以下の事項が適用されます。

(1) 管理者

本アプリにおけるユーザーの個人データの管理者（controller）は ZOELAB です。 連絡先: contact@zoelab.jp

(2) 処理の法的根拠

  • アカウント情報、ユーザーが作成する情報の同期・保存、認証、および購入に関する情報の処理 — ユーザーとの契約（本アプリの利用規約）の履行のために必要な処理（GDPR 第6条1項(b)）
  • 利用状況に関する情報（Google Analytics for Firebase）の処理 — ユーザーの同意（GDPR 第6条1項(a)）。同意はいつでも撤回できます。撤回は、撤回前に行われた処理の適法性に影響しません。
  • 不具合の調査・対応、お問い合わせへの対応、安全管理のための処理 — 本アプリを安全かつ安定して提供するという当方の正当な利益（GDPR 第6条1項(f)）

(3) ユーザーの権利

ユーザーは、適用される法令に基づき、自己の個人データについて、アクセス、訂正、消去、処理の制限、データポータビリティを求める権利、 処理に異議を述べる権利、および同意を撤回する権利を有します。これらの権利は、以下の方法で行使できます。

  • 利用状況の収集に関する同意の撤回は、本アプリの「設定 → アプリ情報 → 利用状況の送信」から行えます（第1条(3)参照）。
  • TaskChute Cloud 2 のサーバー上に保存された情報の消去は、TaskChute Cloud 2（Web版）の退会手続きにより行えます（第7条およびアカウントの削除のページ参照）。
  • そのほかの請求は、上記の連絡先までご連絡ください。本人確認のため、追加の情報の提供をお願いすることがあります。

(4) 監督機関への申立て

ユーザーは、ご自身の居住国、勤務地または権利侵害が生じたとされる場所のデータ保護監督機関に申立てを行う権利を有します。

(5) 国外へのデータ移転

  • TaskChute Cloud 2 は、日本法人である jMatsuzaki株式会社が日本法に基づいて運営するサービスです。日本は、欧州委員会および英国政府から、個人データについて十分な保護水準を確保している国として認定（十分性認定）を受けています。
  • Google LLC（Firebase、Google ログイン）、Apple Inc.（Sign in with Apple）および RevenueCat, Inc. が提供するサービスでは、米国を含む国外でデータが処理されることがあります。 これらの事業者は、標準契約条項（SCC）などの法令上認められた保護措置に基づいてデータを移転します。 Google が適用する保護措置については、Google のデータ移転に関するフレームワークをご確認ください。

(6) 保存期間

情報の保存期間は第7条の定めによります。これに加え、Google Analytics for Firebase に送信された利用状況に関するデータのうち、 個々のアプリインスタンスに関連づけられたデータは、Firebase プロジェクトの設定に基づき 2か月間保持された後に削除されます。 同意を撤回した場合、端末上のデータは直ちに消去されますが、撤回前に送信されたデータは上記の保持期間の満了をもって削除されます。

9. 本ポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。 変更後のプライバシーポリシーは、本ページに掲載した時点から効力を生じるものとします。

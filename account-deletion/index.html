アカウントの削除

タスク管理アプリ「TaskChute Cloud Lite」（開発: ZOELAB）のアカウント削除手順のご案内です。

アカウントの管理について

本アプリを TaskChute Cloud 2 のアカウントと連携してご利用の場合、アカウントは TaskChute Cloud 2（運営: jMatsuzaki株式会社）側で管理されています。 アカウントの削除は、TaskChute Cloud 2（Web版）から行います。

なお、アカウントと連携せずにご利用の場合、削除すべきアカウントはありません。 端末内に保存されたデータは、本アプリをアンインストールすることで削除されます。

削除手順

  1. TaskChute Cloud 2（Web版）にログインします。
  2. 「ユーザー設定」を開きます。
  3. 「アカウント削除」から削除手続きを行います。

ユーザー設定画面はこちらから開けます: TaskChute Cloud 2 ユーザー設定

削除されるデータ

アカウントを削除すると、サーバー上に保存された以下のデータが削除されます。

  • アカウント情報（メールアドレス、表示名など）
  • タスクの記録（タスク名、見積時間、開始・終了時刻、ルーチン設定、セクション設定など）
  • コメント（メモ）およびコメントに添付した画像

端末内に保存されたデータは、アカウント削除後も本アプリをアンインストールするまで端末に残ります。

有料プランをご契約中の場合

TaskChute Cloud 2 の有料プランをご契約中の場合は、アカウントを削除する前に、 ご契約中のプランの解約手続きを行ってください。 TaskChute Cloud 2 の削除手続きの中で解約に関する案内は表示されないため、 ご契約状況を事前にご自身でご確認ください。 なお、TaskChute Cloud 2 の利用規約により、支払い済みの対価は返金されず、 月額制プランは月の途中で利用を終了した場合でも当該月の料金が発生します。
